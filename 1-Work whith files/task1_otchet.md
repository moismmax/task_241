# Отчет по практической работе: Работа в консоли

## 1. Переместиться между директориями

Переход в домашний каталог текущего пользователя:
```bash
cd ~
```

Переход по абсолютному пути в каталог системных логов:
```bash
cd /var/log
```

Переход на один уровень вверх (в родительский каталог):
```bash
cd ..
```

Возврат в предыдущую директорию:
```bash
cd -
```

Переход в корень файловой системы:
```bash
cd /
```

**Разбор команды и параметров:**
- **cd** (change directory) — базовая команда Linux для смены текущей рабочей директории.
- **~** (тильда) — обозначение домашнего каталога текущего пользователя.
- **/** (слеш в начале) — корневой каталог файловой системы.
- **..** (две точки) — ссылка на родительскую директорию (на уровень выше).
- **-** (дефис) — быстрый возврат в каталог, где пользователь находился перед последним переходом.

---

## 2. Вывести список файлов в директории
```bash
ls -l
```
**Разбор параметров:**
- **ls** (list) — утилита для отображения содержимого каталога.
- **-l** (long format) — вывод подробного списка с правами доступа, владельцем, размером в байтах и датой последнего изменения.

---

## 3. Вывести список всех файлов, включая скрытые
```bash
ls -la
```
**Разбор параметров:**
- **-a** (--all) — отображает абсолютно все файлы и папки, включая скрытые (название которых начинается с точки, например `.bashrc`).
- Комбинация **-la** включает одновременно подробный формат (`-l`) и показ скрытых объектов (`-a`).

---

## 4. Создать папку с несколькими уровнями подпапок
```bash
mkdir -p lab1_dir/level2/level3
```
**Разбор параметров:**
- **mkdir** (make directory) — команда для создания новых папок.
- **-p** (--parents) — флаг, создающий всю цепочку вложенных директорий. Если промежуточные папки `lab1_dir` и `level2` отсутствуют, система создаст их автоматически без ошибки.

---

## 5. Внутри папки создать файл и записать в него несколько строк текста
```bash
cat << 'EOF' > lab1_dir/level2/level3/source.txt
банан
яблоко
вишня
апельсин
EOF
```
**Разбор параметров:**
- **cat** — утилита считывания и записи текстовых данных.
- **<< 'EOF'** — конструктор многострочного ввода (Here-Document), считывающий текст до ввода стоп-слова `EOF`. Одинарные кавычки отключают подстановку переменных и спецсимволов.
- **>** — оператор перенаправления вывода: создаёт файл `source.txt` и записывает в него текст.

Просмотр содержимого созданного файла:
```bash
cat lab1_dir/level2/level3/source.txt
```

---

## 6. Переместить файл из одной директории в другую
Перемещение файла `source.txt` из `level3` на уровень выше (в `level2`):
```bash
mv lab1_dir/level2/level3/source.txt lab1_dir/level2/source.txt
```
**Разбор параметров:**
- **mv** (move) — команда перемещения и переименования файлов.
- Первый аргумент — текущее местоположение файла.
- Второй аргумент — новое местоположение.

---

## 7. Скопировать файл из одной директории в другую
Копирование файла `source.txt` из `level2` в папку `lab1_dir`:
```bash
cp lab1_dir/level2/source.txt lab1_dir/copied_file.txt
```
**Разбор параметров:**
- **cp** (copy) — утилита копирования файлов.
- Первый аргумент — исходный файл-источник.
- Второй аргумент — путь и имя создаваемой копии.

---

## 8. Переименовать файл
Переименование `copied_file.txt` в `final_doc.txt` внутри `lab1_dir`:
```bash
mv lab1_dir/copied_file.txt lab1_dir/final_doc.txt
```
**Разбор параметров:**
- В Linux отдельной команды для переименования файлов нет. Для этого используется `mv`: если указать путь в тот же каталог с новым именем, файл переименовывается.

---

## 9. Сравнить содержимое двух файлов
Сравнение исходного файла `source.txt` и переименованной копии `final_doc.txt`:
```bash
diff lab1_dir/level2/source.txt lab1_dir/final_doc.txt
```
**Разбор параметров:**
- **diff** (difference) — утилита построчного сравнения двух файлов.

**Вывод консоли:**
```bash
moismmax@ubuntu:~$ diff lab1_dir/level2/source.txt lab1_dir/final_doc.txt
moismmax@ubuntu:~$
```
**Вывод пустой, так как содержимое файлов полностью идентично.**

---

## 10. Отсортировать содержимое файла по возрастанию и убыванию

Сортировка по возрастанию (в алфавитном порядке):
```bash
sort lab1_dir/final_doc.txt
```
**Вывод консоли:**
```bash
moismmax@ubuntu:~$ sort lab1_dir/final_doc.txt
апельсин
банан
вишня
яблоко
```
**Разбор параметров:**
- **sort** — утилита сортировки текстовых строк (A-Z / А-Я).

Сортировка по убыванию (в обратном порядке):
```bash
sort -r lab1_dir/final_doc.txt
```
**Вывод консоли:**
```bash
moismmax@ubuntu:~$ sort -r lab1_dir/final_doc.txt
яблоко
вишня
банан
апельсин
```
**Разбор параметров:**
- **-r** (--reverse) — меняет порядок сортировки на противоположный (Z-A / Я-А).

## 11. Найти созданный файл по имени, не переходя вручную по всей структуре каталогов
```bash
find ~/lab1_dir -name "final_doc.txt"
```
**Разбор параметров:**
- **find** — утилита для автоматического поиска файлов по дереву каталогов.
- **~/lab1_dir** — каталог, с которого начинается поиск.
- **-name "final_doc.txt"** — поиск файла по точному названию.

**Вывод консоли:**
```bash
moismmax@ubuntu:~$ find ~/lab1_dir -name "final_doc.txt"
/home/moismmax/lab1_dir/final_doc.txt
```

**Итоговая структура созданных каталогов** (состояние после выполнения п.6–8):
```bash
tree lab1_dir
```

**Вывод консоли:**
```bash
moismmax@ubuntu:~$ tree lab1_dir
lab1_dir
├── final_doc.txt
└── level2
    ├── level3
    └── source.txt

2 directories, 2 files
```

## 12. Удалить созданные в ходе задания файлы и каталоги
```bash
rm -ri ~/lab1_dir
ls -l ~/lab1_dir
```

**Разбор параметров:**
- **rm** (remove) — утилита для удаления файлов и каталогов.
- **-r** (recursive) — рекурсивное удаление (удаляет папку вместе со всем её содержимым).
- **-i** (interactive) — интерактивный режим, который запрашивает подтверждение перед удалением каждого файла и директории.

**Вывод консоли:**
```bash
moismmax@ubuntu:~$ rm -ri ~/lab1_dir
rm: descend into directory '/home/moismmax/lab1_dir'? y
rm: remove regular file '/home/moismmax/lab1_dir/final_doc.txt'? y
rm: descend into directory '/home/moismmax/lab1_dir/level2'? y
rm: descend into directory '/home/moismmax/lab1_dir/level2/level3'? y
rm: remove regular file '/home/moismmax/lab1_dir/level2/level3/source.txt'? y
rm: remove directory '/home/moismmax/lab1_dir/level2/level3'? y
rm: remove directory '/home/moismmax/lab1_dir/level2'? y
rm: remove directory '/home/moismmax/lab1_dir'? y
moismmax@ubuntu:~$ ls -l ~/lab1_dir
ls: cannot access '/home/moismmax/lab1_dir': No such file or directory
```

## Разница между абсолютным и относительным путём

- **Абсолютный путь** всегда начинается от корневого каталога (обозначается слешем `/`) и указывает полный маршрут к файлу или папке, который будет работать одинаково независимо от того, в какой директории сейчас находится пользователь. Пример: `/home/moismmax/lab1_dir/final_doc.txt`.

- **Относительный путь** строится относительно текущей рабочей директории пользователя. Он никогда не начинается со слеша. Пример: если мы уже находимся в папке `/home/moismmax`, то относительный путь к тому же файлу будет выглядеть просто как `lab1_dir/final_doc.txt`.
