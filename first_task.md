# Первое самостоятельное задание с пары

1) Установить пакеты `samba`, `bind`, `bind-utils` и любой Python-модуль.

2) Для каждого установленного пакета вывести:
   2.1) версию;
   2.2) список файлов, принадлежащих пакету;
   2.3) зависимости пакета.

3) Проверить службы, относящиеся к установленным пакетам. Если нужная служба не запущена — запустить её и добавить в автозагрузку.
   3.1) Можно ли включить службу и добавить её в автозагрузку одной командой?

4) Найти и вывести конфигурационные файлы пакетов, у которых они есть.

5) Для одной из служб:
   5.1) показать её текущий статус;
   5.2) показать последние записи из журнала;
   5.3) определить, под каким пользователем она работает.

## Критерий приёмки

В отчёте должны быть:
- перечень установленных пакетов;
- команды и вывод, подтверждающие версии пакетов;
- команды и вывод со списком файлов, принадлежащих пакетам;
- команды и вывод с зависимостями пакетов;
- статус соответствующих служб до и после запуска;
- подтверждение включения служб в автозагрузку;
- путь и фрагмент конфигурационного файла хотя бы одной службы;
- фрагмент журнала выбранной службы;
- краткий вывод о различии между установкой пакета, запуском службы и включением автозапуска.


# Первое самостоятельное задание с пары

## 1. Установка пакетов

В macOS используется операционная система macOS 26.6.2, управление системными службами осуществляется через `launchd`. Пакетные менеджеры `apt` и `dnf`, а также система управления службами `systemd` в macOS отсутствуют.

Для просмотра установленной версии Python используется команда:

```bash
python3 --version
```

Для просмотра установленных Python-модулей:

```bash
python3 -m pip list
```

В macOS отдельные пакеты Samba и BIND не устанавливались.

В Linux для установки необходимых пакетов используется пакетный менеджер DNF (Fedora/RHEL):

```bash
sudo dnf install samba bind bind-utils python3-requests -y
```

Устанавливаются следующие пакеты:

- `samba` — организация общего доступа к файлам по SMB;
- `bind` — DNS-сервер BIND;
- `bind-utils` — утилиты для работы с DNS;
- `python3-requests` — Python-модуль для HTTP-запросов.

## 2. Просмотр информации об установленных пакетах

### 2.1. Версии пакетов

В macOS версия Python определяется командой:

```bash
python3 --version
```

В Linux версии установленных пакетов отображаются командой:

```bash
rpm -q samba bind bind-utils python3-requests
```

Для просмотра информации о конкретном пакете:

```bash
rpm -qi samba
rpm -qi bind
rpm -qi bind-utils
rpm -qi python3-requests
```

### 2.2. Список файлов, принадлежащих пакетам

В macOS список установленных Python-модулей можно посмотреть командой:

```bash
python3 -m pip list
```

В Linux для просмотра файлов каждого пакета используется команда `rpm -ql`:

```bash
rpm -ql samba
rpm -ql bind
rpm -ql bind-utils
rpm -ql python3-requests
```

Команда выводит список файлов, установленных соответствующим пакетом.

### 2.3. Зависимости пакетов

В Linux для просмотра зависимостей используется команда:

```bash
rpm -qR samba
rpm -qR bind
rpm -qR bind-utils
rpm -qR python3-requests
```

Для просмотра зависимостей до установки пакета можно использовать:

```bash
dnf repoquery --requires samba
dnf repoquery --requires bind
dnf repoquery --requires bind-utils
dnf repoquery --requires python3-requests
```

Зависимости — это другие библиотеки и программные компоненты, необходимые для корректной работы устанавливаемого пакета.

## 3. Проверка и управление службами

В macOS управление системными службами выполняется с помощью `launchd` и команды `launchctl`.

Просмотр запущенных служб:

```bash
launchctl list
```

Поиск служб, связанных с Samba и DNS:

```bash
launchctl list | grep -Ei 'smb|samba|named|bind'
```

В macOS службы Samba и BIND не установлены в рамках данной работы, поэтому их запуск и включение в автозагрузку не выполнялись.

В Linux соответствующие службы называются `smb` и `named`.

Проверка состояния Samba:

```bash
sudo systemctl status smb
```

Проверка состояния BIND:

```bash
sudo systemctl status named
```

Если служба не запущена, её можно запустить и одновременно добавить в автозагрузку:

```bash
sudo systemctl enable --now smb
sudo systemctl enable --now named
```

Проверка состояния после запуска:

```bash
sudo systemctl status smb
sudo systemctl status named
```

Проверка включения автозагрузки:

```bash
systemctl is-enabled smb
systemctl is-enabled named
```

Команда `systemctl enable --now` позволяет одной командой включить службу в автозагрузку и запустить её немедленно.

## 4. Поиск конфигурационных файлов пакетов

В macOS системные настройки сетевого доступа могут находиться в конфигурационных файлах и управляться через системные настройки.

Основной файл клиентской конфигурации SMB:

```text
/etc/nsmb.conf
```

Проверка наличия файла:

```bash
ls -l /etc/nsmb.conf
```

В Linux основные конфигурационные файлы расположены по следующим путям:

| Пакет | Конфигурационный файл |
|---|---|
| samba | /etc/samba/smb.conf |
| bind | /etc/named.conf |
| bind-utils | Отдельный основной конфигурационный файл не требуется |
| python3-requests | Отдельный системный конфигурационный файл не требуется |

Поиск конфигурационных файлов Samba:

```bash
rpm -qc samba
```

Поиск конфигурационных файлов BIND:

```bash
rpm -qc bind
```

Просмотр конфигурации Samba:

```bash
sudo cat /etc/samba/smb.conf
```

Просмотр конфигурации BIND:

```bash
sudo cat /etc/named.conf
```

Пример фрагмента конфигурационного файла Samba:

```ini
[global]
    workgroup = WORKGROUP
    security = user
    map to guest = Bad User
```

Пример фрагмента конфигурационного файла BIND:

```conf
options {
    directory "/var/named";
    listen-on port 53 { 127.0.0.1; };
    allow-query { localhost; };
};
```

## 5. Проверка одной из служб

Для подробного изучения выбрана служба BIND — DNS-сервер `named`.

### 5.1. Просмотр текущего статуса

В Linux используется команда:

```bash
sudo systemctl status named
```

Для краткой проверки состояния:

```bash
systemctl is-active named
```

### 5.2. Просмотр последних записей журнала

Для просмотра последних 20 записей журнала службы:

```bash
sudo journalctl -u named -n 20 --no-pager
```

Для просмотра журнала в режиме реального времени:

```bash
sudo journalctl -u named -f
```

В macOS просмотр системного журнала осуществляется через команду `log`:

```bash
log show --last 10m --style compact
```

### 5.3. Определение пользователя, от имени которого работает служба

В Linux для определения пользователя процесса `named` используется команда:

```bash
ps -o user,pid,ppid,comm -C named
```

В стандартной конфигурации BIND на Fedora/RHEL служба обычно работает от имени системного пользователя `named`.

Дополнительная проверка:

```bash
id named
```

## 6. Итог

В ходе работы рассмотрены установка и администрирование программных пакетов Samba, BIND, bind-utils и Python-модуля Requests.

Для macOS рассмотрены доступные средства просмотра версии Python, установленных Python-модулей, системных служб и конфигурационных файлов SMB.

Для Linux приведены команды установки пакетов, просмотра их версий, файлов и зависимостей, а также управления службами с помощью `systemctl`.

Рассмотрены конфигурационные файлы Samba и BIND, просмотр статуса службы `named`, получение последних записей журнала и определение пользователя, от имени которого работает процесс.

Установка пакета, запуск службы и включение автозагрузки — три разные операции:

- **Установка пакета** — копирование программы, библиотек и необходимых файлов в систему.
- **Запуск службы** — запуск программы в качестве фонового процесса.
- **Включение автозагрузки** — настройка автоматического запуска службы при загрузке операционной системы.

В Linux запуск службы и включение автозагрузки можно объединить командой `systemctl enable --now`.
